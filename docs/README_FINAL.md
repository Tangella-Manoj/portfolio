## 🔧 Easy Content Updates

### Update Resume (No Code Changes!)
1. Upload new PDF to Google Drive
2. Replace old file (keep same file ID)
3. Done! Link never breaks

### Update Stats/Info
Edit `src/constants/personal.ts`:
- LeetCode stats
- Email, location
- Social links

### Add New Experience
Edit `src/constants/experience.ts`:
- Add new job object
- Build and redeploy

### Add New Project
Edit `src/constants/projects.ts`:
- Add project object with GitHub URL
- Build and redeploy
