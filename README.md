## ⚡ Key Engineering Highlights Featured

- **90% p99 Latency Drop:** Asynchronous bulk disbursement pipeline (500ms → 50ms) using non-blocking I/O and connection pooling.
- **96× Batch Speedup:** Refactored batch processing engine from an 8-hour execution window to < 5 minutes processing 50k+ records.
- **10k+ Events/Minute:** Real-time event streaming pipeline powered by Apache Kafka and Spring Boot consumer groups.
- **300+ Problems Solved:** Strong algorithmic foundation on LeetCode (1446 rating).

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/Tangella-Manoj/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server (with HMR)
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 📦 Deployment

This repository includes automated CI/CD via GitHub Actions (`.github/workflows/deploy.yml`). Pushing to the `main` branch automatically builds and deploys the site with zero downtime.

Compatible with:
- **GitHub Pages** (Built-in workflow)
- **Cloudflare Pages** (`dist` output directory)
- **Vercel** (`vercel.json` included)
- **Netlify** (`netlify.toml` included)
